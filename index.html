Teaching sample

Proposed IBM Skills Network lesson: Python for healthcare professionals — validating structured encounter data. A small, synthetic example demonstrates the distinction between missing and documented information, without making a clinical recommendation.

Exercise: check documentation completeness

Learning objective: use a function to identify fields that are missing without treating a valid false value as absent.

def missing_fields(record, required):
    return [
        field for field in required
        if record.get(field) is None
        or record.get(field) == ""
    ]

demo = {"visit_id": "DEMO-001", "follow_up": False}
print(missing_fields(demo, ["visit_id", "follow_up", "summary"]))
# ['summary']

Synthetic data; educational illustration only. This is not a clinical algorithm or a production validation framework.
